# درمان‌یار — پنل مدیریت کلینیک

پنل فارسی و واکنش‌گرا برای مدیریت کلاینت‌ها، خدمات درمانی، سوابق، جلسات و تراکنش‌های مالی. پروژه با Next.js App Router، PostgreSQL و Drizzle ORM ساخته شده است.

## امکانات

- پرونده کامل کلاینت با کد ملی و چند شماره تماس
- جستجو با نام، ID، کد ملی و تلفن
- تعریف و تخصیص خدمات و مشاهده کلاینت‌های هر خدمت
- ثبت کارهای انجام‌شده و برنامه آینده
- ثبت جلسه با روز، ساعت و مدت
- صورتحساب، تخفیف، پرداخت و مانده حساب
- خروجی Excel برای لیست‌ها، بخش‌ها و کل پرونده
- مرتب‌سازی تاریخ و الفبا
- نسخه دسکتاپ، موبایل و نصب‌پذیر PWA
- سرور آنلاین، سرور محلی و صف ثبت آفلاین

## اجرای محلی

1. یک PostgreSQL در دسترس داشته باشید.
2. فایل `.env` بسازید و `DATABASE_URL` را تنظیم کنید.
3. دستورات زیر را اجرا کنید:

```bash
npm install
npx drizzle-kit push --config drizzle.config.json
npm run dev
```

## دیپلوی با گوشی از طریق GitHub و Vercel

> چون برنامه API و PostgreSQL دارد، GitHub Pages به‌تنهایی مناسب نیست. کد روی GitHub نگهداری می‌شود و اجرای رایگان/آنلاین را Vercel انجام می‌دهد.

1. در اپ یا سایت GitHub یک Repository جدید بسازید و فایل‌های پروژه را آپلود/Push کنید.
2. در سایت Vercel با همان حساب GitHub وارد شوید.
3. گزینه **Add New Project** را بزنید و Repository را Import کنید.
4. در بخش Storage یک Postgres سازگار مثل Neon بسازید، یا از سایت Neon/Supabase آدرس PostgreSQL بگیرید.
5. در **Project Settings → Environment Variables** متغیر `DATABASE_URL` را با Connection String دیتابیس تنظیم کنید.
6. یک‌بار روی دیتابیس آنلاین schema را اعمال کنید. ساده‌ترین راه، اجرای `npx drizzle-kit push` در محیطی است که همان `DATABASE_URL` را دارد.
7. Deploy را بزنید. دفعات بعد فقط تغییرات را از گوشی در GitHub Commit کنید؛ Vercel خودکار نسخه جدید را منتشر می‌کند.

## اتصال سرور

از آیکون تنظیمات بالای پنل می‌توان یکی از این حالت‌ها را انتخاب کرد:

- **سرور آنلاین:** API همان دامنه فعلی
- **سرور محلی:** آدرس یک اجرای دیگر داخل شبکه، مانند `http://192.168.1.10:3000`
- **آفلاین:** فرم‌ها در صف امن مرورگر ذخیره می‌شوند و پس از آنلاین شدن با دکمه همگام‌سازی ارسال می‌شوند

برای اتصال مرورگر به سرور محلی از دامنه‌ای متفاوت، تنظیم CORS و HTTPS متناسب با شبکه نیز لازم است.

## نکته داده اولیه

در اولین اجرای دیتابیس خالی، چند خدمت و پرونده نمونه ساخته می‌شود تا همه بخش‌های رابط قابل بررسی باشند. برای استفاده واقعی می‌توانید داده‌های نمونه را پاک و پرونده‌های اصلی را ثبت کنید.
